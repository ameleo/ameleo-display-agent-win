# Security policy

The agent runs as LocalSystem in the guest and handles the user's input, clipboard, files and
cameras. Please report vulnerabilities privately through GitHub: on the repository page, open the
**Security** tab and choose **Report a vulnerability**. Do not open a public issue. If you cannot
use GitHub, write to opensource@ameleo.fr.

Include what you found, how to reproduce it, and its impact as you understand it. We will
acknowledge the report and keep you informed about the fix.

Fixes go to the `main` branch and into the next release.
